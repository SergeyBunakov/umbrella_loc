**ПРОДУКЦІЯ**

**МАРКІЗИ**

* **Опис:**  Маркізи - це рухомі навіси, що захищають від сонця та дощу. Вони можуть бути різноманітних форм та розмірів, ідеально підходять для балконів, тераси, веранди.

    * **Підкатегорія:**
        * **Ліктьова (горизонтальна):**  Опис:  Маркізи з рухом вздовж лінії стіни, які закривають від сонця та дощу.
        * **Балконна:** Опис: Розроблені спеціально для балконів, з урахуванням невеликого простору.
        * **Коробова:** Опис: Компактні маркізи, що монтуються в коробці, що не заважає вільному проходженню.
        * **Терасна:** Опис: Маркізи для захисту великих терасових зон.
        * **Вертикальна:** Опис: Маркізи з рухом вгору/вниз, які закривають від сонця, дощу та вітру.
        * **Двосторонні:** Опис: Маркізи, що можуть використовуватися з обох сторін.

**М’ЯКІ ВІКНА**

* **Опис:**  М'які вікна - це системи, що забезпечують захист від сонця, дощу та вітру, а також створюють комфортну атмосферу.

    * **Підкатегорія:**
        * **Проста система:** Опис:  Проста система для стандартних потреб.
        * **Система на замках:** Опис:  Система з замками для надійного кріплення.
        * **Система на замках з москітною сіткою:** Опис: Захист від комах та забезпечення приватності.
        * **Ролетна система (тросильна система):** Опис:  Система на тросах для плавного та надійного закриття.


**ПАРАСОЛІ**

* **Опис:** Парасолі - це портативні захисні навіси, що захищають від сонця та невеликих опадів.

    * **Підкатегорія:**
        * **Дерев'яні вуличні парасолі:** Опис:  Екологічні та стильні парасолі.
        * **Металічні вуличні парасолі:** Опис:  Міцні та довговічні парасолі.
        * **Металічні консольні парасолі:** Опис:  Парасолі з консольною конструкцією для зручності використання.


**РЕФЛЕКСОЛІ**

* **Опис:** Рефлексолі - це системи, що захищають від сонця, використовуючи відображення сонячних променів.

    * **Підкатегорія:**
        * **Система LATERAL:** Опис:  Система рефлексолів з боковим кріпленням.
        * **Система ZIP:** Опис:  Система рефлексолів з особливою системою кріплення.


**ТКАНИНИ**

* **Опис:** Різноманітні тканини для маркіз, парасоль та інших конструкцій.

    * **Підкатегорія:**
        * **ПВХ тканина Sioen:** Опис: Міцна та водонепроникна тканина.
        * **Маркізна тканина Sattler:** Опис: Тканина високої якості для маркіз.
        * **Тканина SCREEN:** Опис:  Тканина з функціями затемнення та захисту від сонця.


**ТЕРАСНА ДОШКА**

* **Опис:**  Терасна дошка - це матеріал для створення надійних та естетичних терасових покриттів.

    * **Підкатегорія:**  (перелічіть всі види дошки і їх коротку характеристику)


**ПЕРГОЛИ**

* **Опис:** Перголи - це конструкції з опорами та навісом, що створюють затінену зону.


**ЛІТНІ МАЙДАНЧИКИ**

* **Опис:** Літні майданчики - це готові комплекти для облаштування комфортної зони відпочинку на відкритому повітрі.


**СИСТЕМА ВЕРАНДА**

* **Опис:**  Системи для облаштування веранд.

**ЗАВІСИ ПВХ**

* **Опис:**  Завіси ПВХ для захисту від вітру та дощу.


**ТЕНТИ І НАВІСИ**

* **Опис:**  Тенти та навіси для захисту від сонця та дощу.


**СКЛЯННІ ПЕРЕГОРОДКИ**

* **Опис:**  Скляні перегородки для зонування простору.

**МЕТАЛІЧНІ КОНСТРУКЦІЇ**
